## 3 三条最常踩的红线（详见 `01`／`04`）

1. **未核实的数字不进游戏**：烽堠分级档位数、墩台驻兵数、接力时长——目前都没有出处（`01` §8）。
2. **网络来源只算初核**：进正式文案前须回点校本／出土报告二次核对（`04` §0）。
3. **800 字总预算＋文案三原则**：删评价词、结算只记事实、不写解释性文字（`AGENTS.md` §4、`03` §1.5）。
